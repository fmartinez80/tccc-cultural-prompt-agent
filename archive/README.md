# Archive

Files from older working branches that are not part of the app, kept here so those branches can be removed.

- `knowledge-base-branch/`: the decision log, README and Runway intake prompt from the knowledge-base branches (claude/quirky-mayer-m01mg7, claude/missing-region-files-e0brvf and claude/project-thread-mn1rb4; draft PRs #1 and #2). The knowledge base itself lives on in `app/knowledge-base/`, which is newer.
- `tablescape-test-build/`: the first 3D layout template test build (claude/project-thread-si98xi), with its rules, blueprints and render scripts.
- `early-app-build/`: the docs from the first app build before Runway (claude/upbeat-curie-2k9ion), including REBUILD_SPEC.md. The app was later rebuilt in `app/`.
